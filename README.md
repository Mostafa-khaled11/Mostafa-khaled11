## 🚀 Featured Projects

### ⚽ [Agentic Football Performance Analyst](https://github.com/Mostafa-khaled11/agentic-football-performance-analyst)

An agentic football analytics platform built around structured analytical workflows, deterministic metrics, and evidence-grounded reasoning.

- Orchestrates specialized analytical workflows using **LangGraph**.
- Computes deterministic football metrics and spatial analytics, including **Expected Threat (xT)**.
- Integrates football event data through provider adapters and evidence validation.
- Includes **265 automated tests** and **55 evaluation cases** in its released version.
- Combines **Python, FastAPI, React, and agentic orchestration** into an end-to-end analytical system.

### 💳 [Credit Card Fraud Detection](https://github.com/Mostafa-khaled11/credit-card-fraud-detection)

An end-to-end machine learning system for detecting fraudulent transactions, with experiment tracking, inference APIs, and monitoring.

- Implements **leakage-aware temporal validation** and imbalance-sensitive evaluation.
- Reports a test **PR-AUC of 0.7767** and **Recall of 78.85%**.
- Uses **MLflow, FastAPI, Docker, and automated CI checks**.
- Explores **business-aware threshold selection** and guarded retraining.
- Emphasizes reproducibility, evaluation discipline, and production-oriented ML design.

### 📚 [Human Pose Estimation Bible](https://github.com/Mostafa-khaled11/Human-Pose-Estimation-Bible)

A comprehensive technical reference covering the foundations, evolution, and practical implementation of **Human Pose Estimation**.

- Covers **2D and 3D pose estimation**, benchmark datasets, evaluation metrics, and architectural trade-offs.
- Studies modern approaches including **CNNs, Transformers, GNNs, Diffusion Models, and Vision-Language methods**.
- Includes practical case studies using **YOLOv8-Pose, RTMPose, RTMDet, ByteTrack, image tiling, and multi-stage pipelines**.
- Demonstrates my interest in **research synthesis, architecture analysis, and scientific reasoning**, not only model integration.

### 🔎 [Human Pose Estimation RAG System](https://github.com/Mostafa-khaled11/Rag-system-of-Human-Pose-Estimation-Bible)

A local Retrieval-Augmented Generation system designed for technical question answering over a domain-specific knowledge base.
